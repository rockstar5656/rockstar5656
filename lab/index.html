THE ENGINEERING NOTEBOOK

The interesting part is the tradeoff.

DECISION 001A timeout doesn't mean failure.+

The server can accept a write before its response disappears. A transport exception tells us what the client observed; it does not prove what the server did.

The public order layer preserves this distinction by propagating network errors while turning explicit exchange rejections into structured results. Automatic reconciliation is a future extension, not a capability claimed here.

Read the source analysis ↗
DECISION 002Translate concepts at the edge.+

The command-line interface can name an order STOP_LIMIT while the adapter emits STOP. An explicit mapping concentrates protocol maintenance and gives tests a small, inspectable target.

Read the source analysis ↗
